# 매일 쓰기 — 개인판 사용 안내

Phase 0에는 시연만 있고 실제로 쓸 경로가 없었다. `vv`가 그 경로다.

**왜 이것부터 만들었나**: 안 쓰이면 이벤트가 안 쌓이고, 이벤트가 안 쌓이면
GEPA 루프가 굶는다. 개인판을 매일 쓰는 것이 사내판 성공 확률을 올린다.

---

## 설치

설치할 것이 없다. 표준 라이브러리만 쓴다.

```bash
git clone https://github.com/chayobi03-cyber/Vorivori
cd Vorivori

# 셸 설정에 추가 (~/.bashrc, ~/.zshrc)
alias vv='python3 ~/Vorivori/tools/vv.py'

# 선택: 기본값을 바꾸고 싶을 때
export VORIVORI_HOME=~/.vorivori                 # 원장·볼트 위치
export VORIVORI_PROFILE=~/Vorivori/profiles/personal.json
export VORIVORI_ICS=~/Calendars/work.ics:~/Calendars/personal.ics
```

PowerShell:

```powershell
function vv { python3 $HOME\Vorivori\tools\vv.py @args }
$env:VORIVORI_ICS = "$HOME\Calendars\work.ics"
```

## 하루

### 아침 — 오늘 뭐 있고 언제 비었나

```
$ vv today
── 2026-08-09 일정 1건 ──────────────────────────────────────────
  14:00–15:00  EMC 필터 설계 리뷰  @회의실 A

── 빈 구간 (30분 이상) ───────────────────────────────────────────
  09:00–14:00   300분  ███████████████
  15:00–18:00   180분  █████████
```

빈 구간을 함께 보여주는 이유: **"일정 뭐 있지"보다 "언제 비어 있지"가 실무에서
더 자주 필요하다.** 딥워크 블록을 잡으려면 일정 목록이 아니라 틈이 필요하다.

```
$ vv next
09:30–09:45  주간 스탠드업 ↻   (23분 뒤)
```

### 낮 — 떠오르면 바로

```
$ vv i 쉴드캔 접지점 두 개로 늘려보기
✓ idea-20260809-001  쉴드캔 접지점 두 개로 늘려보기
```

따옴표도 플래그도 없다. **포착이 3초를 넘으면 안 쓰인다.**
프로젝트나 태그는 붙이고 싶을 때만.

```
$ vv i 페라이트 코어 위치 재검토 -p EMC -t filter
```

측정값은 따로.

```
$ vv log 100MHz노이즈=-42dBm -p EMC
✓ 기록: 100MHz노이즈 = -42dBm  (origin=human, 확인됨)
```

CLI로 직접 친 값은 `origin=human`이다 — 사람이 확인한 값이라는 뜻이다.
음성으로 들어온 값은 `origin=ai`가 되고 노트에 **미확인**으로 표시된다.

### 작업 중 — 어디로 보낼지 확인

```
$ vv a 도커 이미지 다시 빌드해서 올려줘
── 분류 ────────────────────────────────────────────────────────
  INFRA_OPERATION   점수 4.0  격차 4.0
  걸린 패턴: 도커, 빌드해

── 프로바이더 ─────────────────────────────────────────────────────
  gemini_cli (클라우드) — role=operate
  승급 사다리: gemini_cli → claude → gpt

── 위험 표면 ─────────────────────────────────────────────────────
  이 작업은 exec 표면을 건드립니다 (명령 실행). 실행 시 정책 판정을 거칩니다.
```

확신이 없으면 그렇게 말한다.

```
$ vv a 터치스톤 파일 로드해서 플롯하는 코드 짜줘
  EMC_ANALYSIS   점수 2.0  격차 0.0
  ⚠ 2위 PYTHON_TOOL와 격차가 좁습니다. 실제 실행 전에 되묻습니다.
```

> 현재 `vv a`는 **분류와 경로만 보여준다.** 실제 모델 호출은 Phase 1이다.
> 지금도 유용한 이유는, 어떤 발화가 어디로 가는지 보이면 라우터를 고칠 근거가
> 쌓이기 때문이다.

### 저녁 — 오늘 한 것

```
$ vv note
```

이벤트 원장에서 노트를 생성한다. 직접 쓰지 않는다.

## 주 1회 — 리뷰

여기가 메모북의 생사를 가르는 지점이다.

```
$ vv review
── 아이디어 현황 ──────────────────────────────────────────────
  inbox 7  active 2  parked 1  done 4

── 14일 이상 방치된 inbox — 여기부터 처리 ─────────────────────────
  idea-20260726-003  (2026-07-26)  s2p 일괄처리 스크립트
  idea-20260728-001  (2026-07-28)  회의록 자동 태깅

  이 목록이 길어지는 것이 메모북이 죽어가는 신호다.
```

방치 목록을 하나씩 처리한다.

```
$ vv t idea-20260726-003 active
$ vv t idea-20260728-001 dropped 수동으로 하는 게 더 빠름
```

**버릴 때는 이유가 필수다.**

```
$ vv t idea-20260728-001 dropped
✗ dropped 상태에는 reason이 필요하다.
  이유 없이 버린 아이디어는 6개월 뒤 같은 형태로 다시 떠오른다.
```

이 제약이 이 도구에서 가장 실용적인 부분이다. 이유가 적혀 있으면 반년 뒤
같은 생각이 떠올랐을 때 그 자리에서 끝난다.

## 명령 요약

| 명령 | 축약 | 하는 일 |
|---|---|---|
| `vv idea <말>` | `vv i` | 아이디어 포착 |
| `vv inbox` | | 미분류 목록 |
| `vv list [상태]` | `vv ls` | 목록 |
| `vv triage <id> <상태> [이유]` | `vv t` | 상태 전이 |
| `vv review` | | 주간 리뷰 + 방치 감지 |
| `vv today [-o 1]` | | 일정과 빈 구간 (`-o 1` = 내일) |
| `vv next` | | 다음 일정 |
| `vv ask <말>` | `vv a` | 분류 + 프로바이더 확인 |
| `vv log <항목>=<값>` | | 측정값 기록 |
| `vv note` | | 일일 작업 노트 생성 |
| `vv status` | `vv st` | 전체 현황 + 원장 무결성 |
| `vv context` | | AI에 넘길 컨텍스트 미리보기 |

상태: `inbox` `triaged` `active` `parked` `done` `dropped`

## 일정 파일 준비

| 출처 | 방법 |
|---|---|
| Google Calendar | 설정 → 캘린더 내보내기 → `.ics` |
| Outlook | 파일 → 다른 이름으로 저장 → iCalendar |
| Apple 캘린더 | 파일 → 내보내기 |

`~/.vorivori/calendars/` 에 두거나 `VORIVORI_ICS`로 지정한다.

### 지원 범위 — 정직하게

| 되는 것 | 안 되는 것 |
|---|---|
| 단발 일정, 종일 일정 | `TZID` 정확한 시간대 변환 (기본 시간대로 처리) |
| `FREQ=DAILY/WEEKLY/MONTHLY` | `FREQ=YEARLY`, `BYSETPOS`, `BYMONTHDAY` 조합 |
| `INTERVAL`, `BYDAY`, `COUNT`, `UNTIL` | `EXDATE` (반복 예외 날짜) |
| 접힌 줄, 이스케이프 문자 | 참석자·응답 상태 |

**해석하지 못한 반복 규칙은 조용히 버리지 않는다.** 원본 일정은 남기고
개수를 알린다 — 빠뜨리면 "일정 없다"는 잘못된 답이 나간다.

```
  주의: 해석하지 못한 반복 규칙 1건. 해당 일정은 최초 1회만 표시됩니다.
```

## 프로바이더 라우팅

카테고리 → **역할** → 실제 프로바이더 순으로 정해진다.
역할 매핑은 `artifacts/provider.routing.json`(양 에디션 공용), 실제 프로바이더는
프로파일이 정한다.

**로컬을 항상 먼저 시도한다.** 비용 때문이 아니라 **데이터가 나가지 않기
때문**이다. 개인판에서도 로컬로 되는 일을 굳이 클라우드로 보내지 않는다.

실패하면 승급한다.

```
1회차  qwen_local   (implement)
2회차  claude       (review)      ← 같은 모델 재시도는 같은 실패를 반복한다
3회차  gpt          (architect)
```

프로바이더 선택은 **항상 정책 엔진을 통과한다.** 페이로드에 크리덴셜이 있으면
클라우드 프로바이더가 차단된다.

```python
c = router.select("DOCUMENTATION", payload="token ghp_...")
# → claude 가 아니라 로컬로 간다
```

## 사내 PC에서는

개인 프로파일이 사내 데이터를 만지는 것이 **가장 현실적인 유출 경로**다.
그래서 사내 프로파일은 호스트에 고정돼 있다.

```
$ vv --profile profiles/enterprise.json status
✗ 프로파일 오류: 프로파일 'enterprise-emc'은 ['*.corp.local', 'EMC-WS-*'] 에만
  고정돼 있다. 현재 호스트: 'my-laptop'
```

반대로 사내 PC에서 개인판을 쓰면 `egress_deny`에 `*.corp.local`, `*.internal`이
걸려 있어 사내 리소스에 접근하지 못한다.

**프로파일 전환 UI는 만들지 않는다.** 전환이 쉬우면 실수로 전환된다.

## 데이터는 어디에

```
~/.vorivori/
├── events.db          ← 정본. 추가 전용, 해시 체인
├── personal/
│   ├── ideas/         ← 아이디어 (Markdown + frontmatter)
│   └── notes/         ← 생성된 노트. 직접 고치지 않는다
└── calendars/*.ics
```

`events.db`가 정본이고 나머지는 파생 뷰다. 노트가 이상하면 지우고 다시
생성하면 된다.

무결성 확인:

```
$ vv status
── 원장 ──────────────────────────────────────────────────────
  이벤트 143건   무결성: 143건 검증 통과
```

### 백업

`~/.vorivori`를 개인 Git 저장소에 넣는 것을 권한다. 단 `.gitignore`에서
`events.db`를 제외할지 결정해야 한다 — 원장에는 업무 내용이 들어간다.

> 크로스 디바이스 동기화는 아직 없다. Phase 2 항목이다.
